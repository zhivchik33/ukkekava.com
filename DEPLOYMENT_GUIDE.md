# Гайд по деплойменту сайту "Ukrainas kopiena Ķekavā"

## 📋 Покрокова інструкція

### Крок 1: Підготовка проекту

1. **Перевірте, що проект працює локально**
   ```bash
   # Відкрийте index.html у браузері або використайте локальний сервер
   python -m http.server 8000
   # або
   npx serve
   ```

2. **Створіть/оновіть .gitignore** (якщо потрібно)
   ```
   node_modules/
   .DS_Store
   *.log
   ```

3. **Закомітьте всі зміни в Git**
   ```bash
   git add .
   git commit -m "Ready for deployment"
   git push origin main
   ```

### Крок 2: Реєстрація домену

**Рекомендовані реєстратори:**
- **Namecheap** (https://www.namecheap.com) - популярний, хороша підтримка
- **Cloudflare Registrar** (https://www.cloudflare.com/products/registrar/) - найнижчі ціни
- **Google Domains** (https://domains.google) - простий інтерфейс

**Процес:**
1. Перевірте доступність домену (наприклад, `ukrainas-kopiena.lv` або `.com`)
2. Додайте до кошика та оплатіть
3. Після покупки домен буде в вашому акаунті

**Приклад цін:**
- `.com` - ~$10-15/рік
- `.lv` - ~$15-25/рік
- `.org` - ~$10-15/рік

### Крок 3: Деплоймент на Vercel

**Vercel - найкращий вибір для статичних сайтів**

1. **Зареєструйтеся на Vercel**
   - Перейдіть на https://vercel.com
   - Натисніть "Sign Up"
   - Оберіть "Continue with GitHub" (рекомендовано)

2. **Імпортуйте проект**
   - Натисніть "Add New Project"
   - Оберіть ваш GitHub репозиторій
   - Vercel автоматично визначить налаштування

3. **Налаштування проекту**
   - **Framework Preset:** Other
   - **Root Directory:** `./` (залиште як є)
   - **Build Command:** (залиште порожнім для статичного сайту)
   - **Output Directory:** (залиште порожнім)

4. **Деплой**
   - Натисніть "Deploy"
   - Зачекайте 1-2 хвилини
   - Отримайте URL: `your-project.vercel.app`

### Крок 4: Підключення домену до Vercel

1. **У Vercel Dashboard:**
   - Відкрийте ваш проект
   - Перейдіть в "Settings" → "Domains"
   - Натисніть "Add Domain"
   - Введіть ваш домен (наприклад, `ukrainas-kopiena.lv`)

2. **Vercel покаже DNS-записи:**
   - Зазвичай це буде CNAME або A-запис
   - Скопіюйте ці значення

3. **Налаштування DNS у реєстраторі домену:**

   **Для Namecheap:**
   - Увійдіть в акаунт
   - Перейдіть в "Domain List" → оберіть ваш домен
   - Перейдіть в "Advanced DNS"
   - Додайте новий запис:
     - **Type:** CNAME Record (або A Record, якщо вказано Vercel)
     - **Host:** @ (або www)
     - **Value:** cname.vercel-dns.com (або IP-адресу від Vercel)
     - **TTL:** Automatic

   **Для Cloudflare Registrar:**
   - Перейдіть в DNS налаштування
   - Додайте CNAME або A-запис згідно з інструкціями Vercel

4. **Очікування:**
   - DNS-записи поширюються 5-60 хвилин
   - Vercel автоматично налаштує SSL-сертифікат

### Крок 5: Перевірка

1. **Перевірте DNS:**
   ```bash
   # У терміналі
   nslookup your-domain.com
   # або використайте онлайн-інструмент: https://dnschecker.org
   ```

2. **Перевірте сайт:**
   - Відкрийте ваш домен у браузері
   - Переконайтеся, що працює HTTPS (🔒)
   - Перевірте всі сторінки та функціональність

### Крок 6: Налаштування редиректів (опціонально)

**Якщо потрібно:**
- Редирект з www на non-www (або навпаки)
- Редирект з HTTP на HTTPS (автоматично у Vercel)

**У Vercel:**
- Settings → Domains → налаштуйте переважний домен

## 🔄 Оновлення сайту

Після кожного `git push` до main гілки:
- Vercel автоматично задеплоїть нову версію
- Процес займає 1-2 хвилини
- Старі версії зберігаються для rollback

## 🆘 Вирішення проблем

**DNS не працює:**
- Перевірте правильність DNS-записів
- Зачекайте до 24 годин (рідко)
- Перевірте через https://dnschecker.org

**SSL не працює:**
- Vercel налаштовує автоматично, зачекайте 5-10 хвилин
- Перевірте, що домен правильно підключено

**Сайт не оновлюється:**
- Перевірте, що зміни запушені в GitHub
- Перевірте логи деплойменту в Vercel
